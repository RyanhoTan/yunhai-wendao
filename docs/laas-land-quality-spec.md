# 《云海问道》陆地自然环境画质要求

用户要求归档于 2026-10-12。本文件保留本轮完整验收标准；进度和实机证据见 `artifacts/laas-quality-20261012/`。此前被用户舍弃的实验保持撤回，本轮从当前 HEAD 重新推进。旧 GLB 制作继续暂停。

## 一、目标与范围

以 LAAS（[Braffolk/fable5-world-demo](https://github.com/Braffolk/fable5-world-demo)）的实际运行画面作为直接视觉参照，追求自然、细密、具有真实光照和生态层次的森林与山地环境。

保留《云海问道》的仙侠世界设定、宗门建筑和地图布局。山体结构、道路走向、森林与城镇位置遵循已有地图图像。本轮只改陆地，海洋与海边维持现状。

继续使用当前 Three.js 工程推进。保留已有资产、任务与存档兼容性。质量判断以玩家实际看到的画面为准，不能仅凭代码量、对象数量或构建通过就宣布画质达标。

## 二、山体与岩石：轮廓、结构、材质共同形成细节

山体必须具有可信的地质结构：连续的山肩、破碎的岩壁、清晰的岩层走向、自然的侵蚀沟槽、凸出的岩台和不规则山脊。

近景岩石和悬崖的细节必须影响真实轮廓与表面起伏。重点画面中的岩壁不能呈现光滑低模轮廓、大块平面、规则多边形切面或重复排列的小岩片。

每种表面具备三个尺度的细节：

- 宏观：整体体量、轮廓、岩层、侵蚀结构。
- 中观：裂隙、断口、石块、根系与局部起伏。
- 微观：法线、粗糙度、颗粒、湿度与颜色变化。

岩石颜色由岩层、风化、湿度、苔藓和地衣共同决定。避免单一噪声覆盖整个山体，避免明显纹理平铺。岩石之间、岩石与地形之间需要自然嵌合，不能像随意贴上的装饰。

## 三、森林：独特树形、真实冠层、自然聚簇

树木具有不同的分枝结构、树干弯曲、倾斜方向、树冠形状、年龄和健康状态。

重点展示的树木应有可信的树干、主枝、次枝和叶簇层次。避免重复的球形、圆锥形树冠，以及只能靠旋转和缩放区分的复制树。

树冠应具有体积、空隙、内部阴影和叶片透光。近景能辨认枝叶关系，中景能看到树群差异，远景形成沿山谷起伏的树冠海洋。

树木按生态逻辑聚簇分布：考虑坡度、土壤湿度、距水体距离、林冠遮光与光照竞争。森林包含密林、疏林、林缘、空隙和更新中的幼树。不能形成均匀撒点、规则网格或等间距排列。

## 四、地表：形成长期生长的生态系统

镜头周围约 10 米内，适合植被生长的地面应具有丰富的实体覆盖：独立草叶、蕨类、灌木、开花植物、落叶、细枝、树皮碎片、小石子、倒木与树根。

裸露土壤、岩石和道路应按照实际用途自然出现，不能让大片平面纹理代替森林地表细节。

植被具备高低、疏密、色相、明度和生长状态变化。包含少量干枯、折断、腐朽和死亡个体。

按位置形成不同的附着关系：

- 树根周围：根部外扩、枯落物、菌类与林下植物。
- 岩壁与岩台：苔藓、地衣、蕨类、局部藤蔓与水渍。
- 石缝：泥土积累与小型植物。
- 路边：踩踏过渡、碎石与逐渐恢复的植被。

所有植物和杂物必须真实贴地。保持道路、山门、台阶和活动场地的通行净宽。

## 五、光照：阴影必须保留颜色和空间层次

森林阴影中应有天空光、地表反弹光和叶片透光。阴影中的植被带有绿色反弹光；阴影中的岩石根据环境呈现冷色天空光与局部反弹色。

林冠内部具有散射光、明暗层次和适量光束。叶片受逆光时能透光，不能始终是不透明的暗色面片。

使用适合当前渲染器的间接光照、环境光照、接触阴影和环境遮蔽方案。细小石块、草簇、树根和建筑基础都要有贴地感。

禁止大面积漆黑阴影、无色灰影、过重环境遮蔽，也不能通过提高统一环境亮度把整个场景照平。

## 六、远景与大气：细节随距离变化，结构仍然成立

远山保留破碎山脊、岩层方向与主要地形起伏。远处森林保留树冠高度变化、群簇关系与受光层次。

大气透视应自然增加远景层次。雾的密度和分布应符合山谷、海拔与天气关系，不能用浓雾遮住缺失的远山、植被或加载问题。

云雾与山体具有空间关系，能够穿行于山谷、位于部分山峰下方，并产生自然的光照变化。

LOD 与替身切换应平滑，避免玩家附近出现明显弹出、树冠突然变形或整片植被突然消失。

涉及全局灯光、天空、雾和后期的调整时，同时对照海洋与海边画面，保证其现有效果维持。

## 七、色彩与动态

整体采用克制、自然的色彩。受光岩石与植被偏暖，阴影与远山偏冷；绿色随树种、年龄、湿度和光照变化。

重要视角具有明确层次：暗色前景框景、受光中景主体、具有空气透视的远景。宗门、道路、山峰与森林应保持清楚的视觉关系。

植物具有分层风动：树干与主枝缓慢运动，细枝和叶片变化更细密。草、蕨和灌木的运动与同一风场协调，避免整片同步摇摆。

可加入适量花粉、浮尘和飘叶。动态效果应在真实移动中自然稳定，避免高频闪烁。采用合适的抗锯齿与细节过滤，保持枝叶、草地和远山稳定。

## 八、必须避免的画面问题

- 光滑低模山体与规则切面的悬崖。
- 重复树形、球形树冠、统一绿色与均匀散布。
- 大片裸露贴图地面，以及明显平铺的噪声材质。
- 漆黑阴影、灰色林冠内部、缺乏透光的叶片。
- 悬浮植物、岩石穿帮、遮挡道路的装饰物。
- 用雾遮掩远景缺陷，或出现明显 LOD 弹出。
- 仅靠滤镜、饱和度和曝光调整就宣称达到 LAAS 画质。

## 九、开发与验收

先查看 LAAS 实际画面与当前项目截图，确定山体、森林、地表、光照和远景的主要差距。

每个可验收模块完成后：

1. 构建并运行当前项目。
2. 用玩家真实镜头拍摄同位置、同时间的前后对比。
3. 对照 LAAS 中相近的环境与景别。
4. 记录视觉影响最大的十项差异，修复前三项后重新截图。
5. 检查真实步行、道路通行、镜头碰撞与御剑观察。
6. 记录实际帧率、帧耗时、绘制调用和三角面数量。
7. 按仓库规则完成 review 和独立本地提交，并记录结果。

至少检查这些画面：

- 地面高度的森林内部。
- 树干、树根、草蕨与落叶近景。
- 盘山路与岩壁。
- 宗门和主山整体。
- 山谷森林与远山。

最后以两类重点画面验收：

- A. 正午森林内部：冠层有体积，林下有层次，地表细节丰富，阴影有颜色，植物自然贴地。
- B. 黄金时段山地远景：山脊破碎，岩壁有结构，山谷形成树冠海洋，云雾具有空间层次。

最终效果必须在玩家自由探索时同样成立。未完成或仍有明显差距的部分，应明确记录，继续迭代。
