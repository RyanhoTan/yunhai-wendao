# 妖兽身体与剑击交互验收

2026-10-08，第一模块，保留原三尾妖灵、石灵外观与首章。新增模型在后续独立模块接入。

角色半径0.55m、高1.8m；妖灵身体采用可旋转水平胶囊，石灵采用半径1.8m、高5.1m的圆柱。尾巴与腿间空隙不作逐部位碰撞。固定60Hz，水平移动每段至多15cm；世界障碍与敌人共同阻挡，敌人追逐/转身/控场位移不能挤入角色。

剑击接触时间0.16s、动作0.45s、间隔0.48s，距离与前向夹角在接触时计算一次。沿用26+境界×12伤害、近敌自动转向、封印保护与血条。死亡后移除身体阻挡。

- 生产构建通过，既有约1MB主包警告保留。
