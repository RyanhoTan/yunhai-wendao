`npm run build` 通过。原有 `tests/character.spec.ts` 五项通过，验证资源等待/重试、暂停/恢复、御剑支撑和完整循环。资源审图分别检查两个角色的站姿、跑步、挥剑、闪避和御剑状态；结果见 `pose-review.json` 与同目录 PNG。零浏览器错误，玄影缺失动画的动作时间为 0、来源为 `rest-pose`，攻击剑尖在伤害窗口朝前。
