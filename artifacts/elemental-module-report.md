# 五行攻击模块验收（2026-10-06）

1–5选择金木水火土，T召出五枚元素、环绕后定向发射。共享3.2秒冷却，每轮24真气；角色地面与御剑均可施放。飞剑、叶藤、水滴、火舌和岩石几何由本作制作，three.quarks0.17.1负责共享拖尾和命中粒子。参考源码与差异见[来源说明](../docs/elemental-references.md)。

生产构建通过。两项新攻击测试覆盖五种真实输入命中、切换不能绕过冷却、暂停冻结、重试清理与重复重置的几何/纹理计数；[实际输入数据](qa/elemental-input.json)在RTX4050上零错误，10张JPEG原帧来自未暂停的渲染回调，保留原画布像素。

当前[模块测试结果](qa/elemental-module-tests.json)为五项中四通过、一项慢帧移动时序失败；该旧测试固定按住W600ms，释放后实际仅移动0.68m，未达原0.7m断言。改为持续真实输入直到原距离断言达成，[目标复测](qa/elemental-ui-focus-tests.json)通过10.1秒，没有降低距离要求。较早满内存下的截图/重载超时保留于[初轮记录](qa/elemental-ui-initial-tests.json)。五个唯一用例当前均已验证，不宣称单轮五项全通过。

[画面manifest](elemental-module-20261006/evidence.json)包含五种元素各环绕、发射共10个1280×720状态，全部RTX4050硬件、错误0、声明预算通过。所有五种原图及真实输入原帧已查看；自查调整环绕元素为78%尺度、蓄势姿态和初次出现比例，减少遮挡角色。批次分辨率随画布更新，近场保留轮廓和清晰发射方向。

资源采用10个模型/拖尾槽、8个各18粒子的命中槽、共享几何/材质和一张原创64×64粒子纹理。无动态创建材质或模型池增长。页面离开先保存并释放粒子、世界和WebGL上下文；BFCache保留页面的情况继续保留原实例。自查未发现待处理功能缺陷，资源和帧率仍受共享工作站内存压力影响，不能据此保证所有设备的性能。
