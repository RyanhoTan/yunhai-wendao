# 连贯开放地图与首章节奏

- 地图边界约600×600米，无关卡传送。可步行、御剑、回宗门；地图展示所有主要地标。
- 出生 (0,50)：前方宗门、师长 (0,32)；首任务可通过真实交互领取。
- 宗门外山道：近处3株灵草，妖灵蓄力攻击教学；两条可绕行路线。
- 松风林西侧 (-110,-70)：第一个阵眼，守护妖灵、旁支宝箱。
- 玉镜潭东侧 (105,-135)：第二个阵眼，以御剑穿越山谷；更密集守护者。
- 望月台北侧 (0,-245)：第三个阵眼，路线更长但有休息和采集。
- 镇山台 (0,-280)：石灵封印随阵眼解除，圆形地面预警、蓄力冲击与恢复窗口。
- 通关后保留开放探索；背包炼丹、任务札记、地图、设置、手动/自动存档、死亡回宗门。
- 大型地标与远山帮助定向，游戏镜头必须同时保留玩家、近处威胁和前行路线。

## 自然山谷与海岸
- 陆地采用独立固定种子多尺度噪声，平整道路/任务平地和湖盆；新地形仍为原首章坐标空间。
- 1m 近景/2m 远景 LOD 分块地形与连续远山带，按坡度、高度和山道权重混合草地、土、露岩；远山只作地图边界外背景。
- 南部 (0,65) 到 (0,145) 留清晰通路接入沙丘；听潮海岸约 z=196 的曲线岸线，主通路不设大礁石。
- 角色可沿岸步行、到约0.75m浅水处涉水；深水需已解锁的御剑。御剑抬升基准为海面而非海底。
- 树木/草植不进入宗门/阵眼/山道/海滩/湖面或陡坡；礁石碰撞与镜头包围盒来自原创几何。

## 听潮坊古镇长街

- 位于宗门东南侧，中心(125,83)，南街口z=130、北街口z=38，约92m南北石街。四段支路(0,65)→(52,72)→(87,127)→(125,137)从宗门接入南入口，M地图显示金色连通路线。
- 东西各六铺，沿z=53至115.5排列；每铺宽10.4m、深7.4m，正门留通畅中心走道。四座二层门面，其余单层；上层为街景建筑。
- 地基高3.4m，周围12m范围平滑接回原山谷；树木、草与森林代理避开铺面、街道与入口。北端靠山，南端连接宗门支路。
- 石街与商铺地板轻微抬高避免共面，青瓦顶有木背面与填充山墙；进入店铺能够抬镜头，侧墙/后墙、柜台/货架、屋顶和牌坊使用Box3实体与镜头代理。
- 十二铺分别显示药庐、茶舍、书斋、织坊、陶馆、酒肆、米行、香铺、笔庄、糕屋、食坊、杂货；每铺原创陈设，门口与店内中心走道开放。
- 真实键鼠从新游戏走到南入口，穿过长街、进出两侧铺面；店内存档重载保持位置。御剑在屋顶上方禁止直接收剑，移动到长街/巷道后落地。
