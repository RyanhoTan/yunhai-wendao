# 高山宗门模块验收

宗门、导师和出生点共同提升至90m峰顶。约660m的五折盘山路连接山脚与宗门；三阵眼间增加山岭环线，真实地形阴影与等高线用于大小地图。原任务、战斗及实体ID保持，加载旧存档重新采样地面并从墙内恢复到附近安全点。

当前版本生产构建通过。最终8项检查约5分钟通过：首章键鼠通关及保存重载、完整步行上山和峰顶续档、最低御剑高度、旧存档安全恢复、敌人退回贴地、地形网格和稀疏林地。另有当前版本坡度及旧水域fixture三项通过。之前22项相关回归包含完整下山至城镇/海岸、山岭环线、大地图、小地图、森林和重试；最终改变山体宽度及安全存档后重跑上述受影响检查，没有把所有早期检查称为最终修订版本的全量验证。

道路中心和左右2.5m、每0.5m采样最大纵坡约0.476（限0.55）。此前被旧桥顶面、环线接头、重叠道路和峰顶广场抬高的局部坡度已修复。独立只读review检查道路、实体、LOD、飞行和保存，无遗留确定缺陷。

`module1-manifest.json`包含最终六张1280×720 RTX4050实机检查。输入测试与截图采集串行运行，避免桌面合成器在并行浏览器间产生错误帧。PNG已人工查看；均非空白、零浏览器错误。峰顶308calls比起始300预算多8次（约2.7%），614297三角/189几何/42纹理在限内；其他五场景全部预算内。这是模块阶段性能记录，未作帧率承诺。

真实路线证据：`road-start.png`、`road-halfway.png`、`temple-summit.png`、`summit-map.png`与`ascent-input.json`；环线证据为`circuit-map.png`与`circuit-input.json`。中间采集、失败和通用回归输出保存在独立子目录，最终画面以manifest为准。后续动态瀑布溪谷、玉镜潭和最终基线仍待完成。
