# 瀑布水系材质统一 · 2026-10-09

瀑布、玉镜潭和下游溪流复用现有大海的水面着色，包括水深吸收、浅水透色、Fresnel 天空反射、日月高光、天气衰减和远景雾色。原先河流只有底色与亮条纹，缺少视角和水深变化。

- `src/world/WaterSurface.ts` 提取现有海洋的共用着色函数及天气 uniforms。月面贴图、太阳/月亮方向、云雨状态和云流时钟均共享引用。
- 河道增加横向采样，潭水增加同心环采样，深度来自角色使用的实际地形。波纹仅改变法线，水面高度与瀑布接缝保持连续。
- 瀑布采用沿落水方向的细流水纹和泡沫；落水点增加局部泡沫。潭面与溪流重叠区按潭面实际 64 边形遮罩，避免透明颜色重复叠加。
- 统一 shader 保留海洋原有波浪和岸边破浪。不同水面仅调整波纹及泡沫形态；未增加贴图或额外渲染通道。
