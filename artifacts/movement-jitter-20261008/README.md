# 移动画面抖动修复 · 2026-10-08

## 原因与修复

玩法使用固定 60Hz 更新，但渲染直接使用最后一次逻辑位置，相机也逐帧瞄准这个位置。刷新率较高或帧间隔波动时，人物位置会重复停住再跳一步，相机转向进一步放大顿挫。

增加前后逻辑状态的渲染插值，覆盖角色、妖兽、护盾与攻击预警；相机、天气光照跟随相同的显示位置。插值仅用于绘制，绘制后恢复完整原始欧拉角、位置及世界矩阵，碰撞、扣血、AI、存档继续使用固定步的真实状态。显示状态比逻辑状态最多晚一个固定步（约16.7ms）。新游戏、读档、重试和测试场景重置插值历史，暂停与截图冻结保持稳定。

主任务 review 与画面基线检查发现四元数回写会改变 XYZ 欧拉角的表达，影响既有 yaw 转向。最终采用保留原始欧拉角恢复，并加入跨越 ±179° 的回归断言；未更新或放宽图像基线。
