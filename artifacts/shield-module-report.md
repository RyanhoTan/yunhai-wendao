# 五行透明护盾模块（2026-10-07）

护盾已接入人物实际游戏。1–5选金、木、水、火、土，Z或HUD护盾按钮施放：18真气、持续6秒、施放起10秒共享冷却；三个境界吸收上限42/60/78。切换元素不改变已开启的护盾，也不刷新冷却。受击先消耗护盾，溢出扣气血；到期/破盾渐隐，暂停冻结，重试清空，地面和御剑均跟随人物。
