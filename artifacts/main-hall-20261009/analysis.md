# 主殿参考观察与验收约定

参考为同一建筑的正面、右侧、背面设计图；适合程序化三维重建。
物体类型：矩形台基上的两层重檐庑殿式主殿，建筑硬表面、重复构件、静态场景物件。

- 宏观：三层灰石台基、中央宽阶、下层宽殿与出檐、上层窄阁与独立四坡屋顶。
- 中观：朱红圆柱、米白墙面、门窗木框、檐下梁枋与斗拱、石栏杆和木栏杆。
- 微观：青绿半圆瓦垄与瓦当、金色翘角端帽与宝顶、格扇细棂、梁枋青金饰线、石砖错缝。
- 关系：柱脚落在石台上；斗拱在柱头并托住檐梁；阁楼穿过下层屋顶；瓦垄贴合四坡曲面；匾额在前檐中央。
- 材质：青绿釉瓦（介质、半光泽），朱漆木（介质、绸面），灰石（高粗糙度），米白灰泥（漫反射），金色饰件（金属）。
- 识别关键：下层屋面宽而低缓、上层阁楼宽约下层的 0.54、两层均四坡且角部上翘、前侧密排格扇、后侧墙窗分区。
- 不确定项：内部梁架、室内家具和真实尺寸未展示；仅补足可行走空间，不宣称考据级复原。梁枋彩绘与小兽按实时游戏预算简化，不投影整张参考到模型。

完成标准：保留现有 27×20m 石台与地形接口，正/侧/后/斜侧观察均有实体深度；三层台基、双重檐、朱柱、格扇和匾额清晰；中央入口可步行进入，门窗/柱/栏杆碰撞与镜头遮挡匹配。模型分部命名、可单独选取和拆分；静态细节按语义部件合批，新增模型目标 <90k 三角形、<65 draw calls。初始 70k 预算调整为 90k，保留了参考所需的四坡密排实体瓦垄。

实机检查：峰顶步行进殿、横向门窗阻挡、背墙与相机、保存恢复、御剑远眺。画面检查使用原生 Three.js 浏览器渲染，并检查参考对应的三个立面和四分之三视角。
