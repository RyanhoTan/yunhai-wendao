## 这批实际改变了什么

- 将原来混合在 `NaturalForest.ts` 的分布、材质、实例与 LOD 拆为各自模块。组合入口只负责组装；原草、蕨、落叶几何在最初拆分时逐属性核验相同，证据见 `forest-validation-r0/responsibility-split.json`。后续树木安置、冠层、碰撞和渲染为有意改动，不宣称整个最终算法保持旧字节。
- 三种树形具有幼树、成年、偏心分叉老树、受损疏冠四种结构，实际改变主干曲线、分叉高度、主次枝和叶簇。近景使用独立约 10–26 厘米的叶片；较宽的三维叶簇沿次枝展开。实例仍共享 12 个原型，不能据此称每棵树已经独一无二。
- 中远景从同一近景叶簇生成，保留各高度层和方向上的实际轮廓支撑。开始时虽然三个 LOD 的包围盒相同，局部真实轮廓仍缺失最多 5.456 米；现已修正几何，不能用复制包围盒代替此项验证。
- 近/中/远层在 10–16 米过渡范围内共享互补权重与世界坐标抖动，叶、木、阴影共同使用主玩家镜头的权重。阴影镜头不重新决定森林 LOD；远景木与叶采用各自材质及孔隙纹理。
- 树干有真实节疤起伏和固定根部；另加细树皮凹凸。叶片使用已有直射光的阴影结果增加薄叶透光及天空散射，未提高全局环境亮度。树干慢摆、枝叶细摆沿共同世界风场变化；旧草蕨的低频结构改造仍属于后续地表模块。
- 倾斜主干的步行碰撞圈按身体高度扩展，相机加入主干/分叉段的保守包围盒并使用已有静态索引。根部按实际高度场座落，冠幅参与道路/建筑保护距离。御剑状态的树干实体碰撞尚未完成，不能把相机保护写成空中身体碰撞已完成。

## 十项视觉差距与前三项修正

`forest-r3/` 是三图诊断，不是完整八图验收。原图显示枝形改善但长裸枝和小叶帽仍像冬季疏林。先修下面前三项，再拍 `forest-r4/r5`；这些改进仍不足以称 LAAS 达标。

| 排序 | r3 或继承问题 | 本批修正和重新截图后的结论 |
| --- | --- | --- |
| 1 | 主次枝末端叶帽过小，裸枝占画面，冠层体积不足 | 次枝沿程展开更宽的三维叶簇，成年与老树有更多实际叶片，受损树占比降为少量；最终林内能辨认枝叶和冠层空隙，但整体林下覆盖仍明显不足 |
| 2 | 中远景局部高度轮廓缺失，即使整体 bounds 相同 | 按 8 高度层和 16 方位保留真实近景极值及叶簇；最终 CPU 实际支撑差为 0，移动仍需视觉检查；山谷远景尚未形成树冠海洋 |
| 3 | 平直树干与简单条纹缺少近景解剖与表面起伏 | 主干增加径向/纵向几何节疤及凹凸，固定根部、弯曲身体圈和相机保护；最终近景仍有重复条带感，根边生态为空，此项仅部分改善 |
| 4 | 草簇之间仍暴露大片绿地，蕨叶与落叶过规则 | 本批保留旧草蕨和落叶主体，下一步需替换为细密、有疏密变化的实体地表 |
| 5 | 根周围缺腐朽物、细枝、树皮、菌类与倒木 | 根座落回归通过，但未制作长期生长的根边生境 |
| 6 | 树种、年龄随机分配、约 5.8 米最小间距且共享原型 | 仍未完成坡度/湿度/林冠竞争驱动的聚簇、空隙、更新幼树和个体结构变化 |
| 7 | 山谷冠层稀，裸坡大块暴露 | 远景代理修正并保持高度结构，但现有安置保护与生境分布仍让山谷稀薄 |
| 8 | 大面积灰岩、主山环带和远山规则面 | 本批未修改山体；前两地质批已记录，后续继续迭代，不能用新树掩盖 |
| 9 | 叶片细节远近与运动稳定性尚不足 | 孔隙 mip、细叶过滤与世界固定过渡已加入；离散移动帧不能代替长时间闪烁及所有 LOD 弹出验收 |
| 10 | 森林阴影仍缺复杂反弹、接触和空气层次 | 薄叶使用已有天空/带阴影直射光，阴影保持绿色；根、石、建筑基础的完整接触光照和山谷云雾尚未完成 |

重点 A 正午森林：冠层已有可见改善，10 米地表和根边生态仍未通过。重点 B 黄金山地：主山、远山、山谷树冠海洋与谷雾仍未通过。空地和未精修地表主导若干实机画面，触发画质技能的自动未达标条件；不根据测试或面数给予更高评价。

## 验证与成本

最终 `forest-canopy-validation-r7/` 四项 CPU 检查通过，源码在检查前后稳定，含源码副本、测试自身和依赖清单哈希。检查真实叶尺度、有限坐标/正常法线/索引、固定根部、风动 bounds、实际 16 方位×8 高度轮廓、结构差异、10 米详细 LOD、连续权重与主镜头/阴影一致性。

`forest-validation-r1/` 与 `forest-polish-r1/` 两项全世界 CPU 回归通过（31.8 秒）：1,398 棵树、全部原 grove 有树；285,582 个草根抽样无悬浮，落叶高差 0.003–0.0446 米；四条道路按 0.2 米纵向、横向 -4/-2/0/2/4 米采样共 45,820 点，岩墙、步行树圈和身体高度树干相机包围盒的阻塞均 0。实体数量只证明覆盖/回归范围，不代表地表自然或画质达标。

## 2026-10-14：实机黑色颗粒修正

原 [独立 review](forest-review.json) 绑定 r5，确证 F1 黑粒、F2 预算与 F3 旧落叶消退例外；历史报告保持原字节。F1 隔离实验 r1 中，实际关闭树皮 bump（3 次 uniform 覆盖）或阴影（21 次覆盖）仍有黑粒，而临时 majority LOD 消除它；majority 是硬切诊断，不能作为生产方案。r2 实际镜头差 7.30 米，comparison 标记无效并保留。

[有效 r3 诊断](forest-render-diagnosis-r3/comparison.json) 的镜头偏差仅 0.000003521 米；实际相同世界阈值/权重仅移到片元材质、纹理与导数计算之后，13 个真实 shader 执行替换，三个非 UI/非玩家区域 RGB 均不超过 8 的像素从 1093/764/1222 降为 0/0/0。原图仍是局部诊断，不能证明整个世界达标。此结果支持早期非均匀 discard 引起当前材质计算黑粒的判断；未声称已经量测到具体 GPU 中间 NaN。

生产代码同样将完整覆盖判断放到 standard/depth main 末尾并更新缓存键 v6，保留世界风场、互补权重、阴影和全部几何。r7 CPU 增加 ShaderLib 生成后覆盖位置须在法线/粗糙度/输出过滤之后的回归；四项 5.8 秒通过。修正版 r6/game-RyRK3zeq.js 八图、严格同镜头/海岸、实际 shader 与源码字节均通过；真实输入和日夜雨天兼容重新验证，合计两项 2.4 分钟。移动原图 [转镜](forest-runtime-r2/trunk-orbit-16.png)、[冠层飞行](forest-runtime-r2/flight-travel-0.png) 可看到细干已恢复带环境颜色的材质。该修正没有关闭阴影、提高统一环境光、浓雾遮挡或换成硬 LOD。

具体修正的 [独立核对](forest-review-fix.json) 已确认 F1 在核证生产证据中修复，没有新增功能阻断；F2 预算、F3 落叶例外、生态/根边/个体树形/远山/全时序质量继续开放。
