## 失败尝试与证据归档

`rejected-r1/` 保留首次被审图拒绝的裁切截图；`review-r2.json` 与 `snapshots-r2.json` 属于中间取景版本，不能作为最终批准。后续有界面图形后端发生 EGL/GPU 上下文错误或实际缓冲不足，见 `after-r10`、`after-r11` 报告与 `buffer-backends*.json`。`update-r3` 至 `update-r8` 记录软件截图超时/中断；最终在 QA 冻结缓存修复后通过，不以失败画面作新基线。

历史测试路径写出的本轮结果复制到 `raw/`；[归档清单](archive.json) 记录新结果与恢复历史原件的准确哈希，24 个历史文件均按 HEAD 原字节恢复。旧地形/水域源函数没有随截图更新而修改；水岸图像变化来自完整视口及测试镜头重置。

保留版本的主山宽台地、大岩面、远峰轮廓与树冠体积仍有简化。当前绘制调用和面数超过初始预算；不宣称稳定 60 FPS、参考库画质等同或像素复刻。独立代码与审图结论见 [review.json](review.json)。本轮未继续旧 GLB、未提交外部模型任务、未修改海面或海岸资产。
