# 当前地图 LAAS 风格调整

用户要求：参考 Braffolk/fable5-world-demo 的自然环境风格和已采用的 map-v1 图，改善当前可玩地图的植被密度、草地覆盖和山体高度。本轮调整当前游戏；没有调用生成服务，没有接入或改写其他工作中的 Meshy 地形资产。

## 模块一：植被与地表

- 树木由原实现实测375棵增至1450棵，十片林区连接山肩与西林；林地范围占陆地6m采样点34.4%，不是实际树冠像素覆盖率。
- 实体草地由2160草簇增至89559草簇，另有10150林下草、1815蕨和5800落叶；117601个通过道路/建筑/水体/坡度/树干排除的草位中76.15%放置实体草簇，这不是全地图面积覆盖率。
- 地表加入多尺度暖灰层理岩石、地衣苔藓、暗绿草坡与干湿土色变化；保留现有WebGL渲染器。未移植参考项目的WebGPU、侵蚀模拟或GI引擎。
- 树根与落叶贴合共同高度场。新增草根完整采样下沉、陡变位置排除，以及跨坡单元/LOD迟滞的近身细节保护。
- 独立review复查2193598个草根，最高悬空3.002mm，超过1cm为0；所有草位近身LOD检查无错误。少量草根在曲面上会埋入，最深约26.3cm，完整草束无法精确弯贴地形。
- 林下草/蕨共享实例原型，重叠林区共享24m单元；几何缓冲从首轮334.85MiB降至236.82MiB，减少29.3%，仍高于原稀疏森林的66.73MiB。

验证：生产构建通过；林地分布/根点/LOD、地形射线、真实林间步行/御剑、西林路线及存档恢复，共5项检查通过，最终新增贴地/LOD检查再次通过。`before/`为改造前六视角，`vegetation-r3/`为最终六个RTX4050硬件视角；页面/控制台错误均0。真实W、F、Space及鼠标转镜头行走11.92m，飞行净空25.89m。历史QA文件测试时写出的新结果已复制至`regression-vegetation/`，历史文件原字节恢复。
