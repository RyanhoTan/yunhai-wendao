# 云海问道 · 云岚初境

国风幻想 3D 修仙游戏，电脑键鼠优先。首章包含约800×600米的连贯山海地图：云岚宗在约90米峰顶，约660米连续盘山路连接山脚与庭院；松风林、望月台、玉镜潭接成山岭环线，两级瀑布经浅溪流入南部海湾。还有听潮海岸、听潮坊古镇商街、西侧苍翠林与镇山台。可自由探索、御剑飞行、即时战斗、采药炼丹，完成历练后筑基。首章结束后仍可探索灵匣与未收集的灵草。

## 运行

需要 Node.js 22 或更新版本，以及支持 WebGL 2 的电脑浏览器。推荐近期 Chrome / Edge；本次验证使用 Chromium 148 与 RTX 4050。

```sh
npm ci
npm run build
npm run preview -- --port 4194
```

打开 http://127.0.0.1:4194/ 。开发模式：`npm run dev`，默认端口 5188。

向前与沈清尘交谈，带回三株青灵草，领取心诀并突破练气圆满。随后清除阵眼附近妖灵并注入灵气，解除北方石灵封印，击败石灵后筑基。红色蓄力圈提示敌人重击；闪避带有短暂无敌时间。落地恢复灵气，真气耗尽会自动降落。镇山结界要求落地战斗。

妖兽身体会挡住步行与闪避，可以从侧面绕行；近战在挥剑接触时按距离与朝向判定，每次挥击对同一目标只扣一次血，死亡后解除阻挡。西部林道与阵眼附近有四只苍狼妖兽，东部与北部阵眼附近有两只赤脊兽，均有独立骨骼动作；旧存档保留原敌人ID与已击败状态。[模型来源与适配](docs/creature-sources.md)。

五行诀用24真气，五种形态共享3.2秒冷却，向镜头前方发射，切换元素不会刷新冷却。归墟用32真气、冷却9秒，前方6米范围持续3秒，击败妖灵各返还4真气。灵压用28真气、冷却6秒，只能落地施放，震退近身妖灵并打断扑击；墙体与树干阻挡位移。石灵保留封印保护与控场抗性。剑斩带短暂金色剑气，T/G/V带抬手施法姿态。

按Z开启透明球形护盾，人物在球内仍清晰可见；金为淡金、木为青绿、水为水蓝、火为红、土为棕黄，随行走与御剑移动。消耗18真气，持续6秒，施放起10秒共享冷却；三个境界分别吸收42/60/78伤害，溢出才扣气血。五行外观不同，当前防御数值相同；切换元素不重染已开盾或刷新冷却。命中产生波环，到期/破盾渐隐，暂停冻结、重试清空。

按M查看金色盘山路，从峰顶庭院沿五次折返下到山脚，再向南沿通路到听潮海岸。道路有石面与灯杆提示方向，也可沿相同道路徒步上山。沙滩可以步行，浅滩可涉水；深水需御剑，F 不会让人物落到深海。海上真气耗尽时自动返回浅滩，海上存档重载会选择避开礁石的安全沙滩。

按 M 查看听潮坊，下到山脚后沿东侧通路到南街口。约92米长街两侧各六铺，药庐、茶舍、书斋、织坊、酒肆等均能步行进入，店名会显示在右侧位置提示。店内可以保存并继续；解锁后可御剑越过街区，在长街或巷道收剑落地。当前商铺提供探索空间与货架陈设，二层为建筑门面，尚无上楼、商人或交易系统。

宗门西路绕主峰接松风林，再向北经望月台、东岭与玉镜潭形成探索环线，三阵眼位置沿用。东岭叠瀑谷有约40米和13米两级瀑布，瀑布、潭水和溪流与大海共用水深透色、天空倒影与日月高光，落水处保留细流水纹和泡沫；玉镜潭和下游约0.5米浅溪可以涉水，向南一直通到海湾。地图显示实际水系与等高线，普通暂停会冻结水面；轻缓动效冻结波纹，云倒影继续与天空同步。[水材质验收](artifacts/water-material-20261009/README.md)。

按 M 找到地图西侧的苍翠林，从松风林向西沿林道进入。此处在原地图边界之外，扩展约200米宽陆地，林道顺着坡面穿过林下与两处空地。可以步行、御剑掠过林冠、保存并重载位置；新林区当前提供自由探索环境。其他山谷仍保留大片草坡与通路，原海洋和湖岸保持。

设置包含静音、音量、高/轻量画质、轻缓动效和全屏。轻缓动效保留行走与攻击动作，减少环境晃动和镜头震动。

世界默认跟随本机现实时间显示昼夜，夜间采用Emotive Engine原月面贴图及Full Moon外观，保留星光与冷色月光；月面直径按反馈扩大至初版3倍。按P打开开发天气面板，选择现实同步或手动预览，调整时刻、云量和雨量，也可选晴空/阴云/落雨。随机天气开关每2–4分钟平滑切换晴阴雨；手动调节天气会关闭随机。面板暂停战斗，背景仍可右键转镜头；天气偏好独立保存，手动模式可随时改回现实同步。雨随步行与御剑高度移动，并受到地面、屋顶遮挡。

## 存档

任务、境界、物品、已采灵草、阵眼、灵匣、已击败妖灵及位置保存在当前浏览器的 localStorage。关键事件、每 15 秒及离开页面时自动保存；暂停菜单可手动保存。标题页设置不会改写进度。死亡重试保留成长与任务；损坏存档会退回可开始新游戏的标题页。旧版地面存档会重新采样高山地形并寻找避开墙体、岩石的落脚点。点击“重新启程”会重置当前浏览器进度。

## 资产与来源

主角与师长采用正常人体比例的蒙皮模型。按用户指定，基础轮廓与动作来自 [SamuraiThirdPersonTemplateThreeJS](https://github.com/achrefelouafi/SamuraiThirdPersonTemplateThreeJS)：dark_igorek 的 Shadowflame Samurai 模型为 CC BY 4.0，动画为 Mixamo 游戏用动作。移除原头盔与蒙面，另行创作面部、五官、束发、交领与衣片，改为玉色国风剑客。完整来源、改动及许可见 [角色来源](docs/character-sources.md)，署名随公开构建资源携带。

头部与照明参考 [long-wind](https://github.com/jbang2004/long-wind) 的 Three.js 实现思路，重新塑造颅骨、下颌、眉弓、眼窝与眼睑、鼻翼和唇形，采用自制皮肤微表面与连续发际线；暖阳、冷天光与克制补光改善背光可读性。人物脸部仍为风格化原创几何。

听潮坊参考同一项目的木构白墙、青瓦檐廊和招牌批次思路，重新创作地形、街道、十二铺模型、牌坊、悬灯和分品类摆设。八张程序纹理与十三匾额图集由 Canvas 绘制，没有复制参考街道、模型或贴图。商铺按距离切换细节，近处保留完整可进入空间。

剑、三尾妖灵、镇山石灵、古建、山体、植被、灵草、阵眼和灵匣由本项目程序建模。地表、石材、莲纹和宗门匾额由 Canvas 绘制；UI 使用原创 SVG 图标。音效、风声与五声音阶背景音由 Web Audio 合成。没有外部生成 API 作业或费用，具体来源见 [资产清单](artifacts/asset-manifest.json)。

本轮参考 [coastal-simulation](https://github.com/iamtechartist/coastal-simulation) 的海岸观感与 [THREE.Terrain](https://github.com/IceCreamYou/THREE.Terrain) 的自然地形、材质混合和植被分布思路；没有使用它们的示例地图。新世界以原创噪声生成、地形 LOD、程序树木和自绘图集构成，保留原首章任务坐标。

森林与山地参考 [verdant-forest](https://github.com/Leonxlnx/verdant-forest) 的 Three.js 植被、枝干生长和地表分层思路，重新创作弯曲树干、非对称枝冠、折面真叶、蕨草和贴坡落叶。六片原疏林加苍翠林的植被集中成片，并避让当前道路与水系；地图、模型、材质与布局由本项目制作。树群和草地按空间单元切换细节，山坡混合草地、腐殖土、破碎岩面和苔藓。

五行形态、粒子纹理、旋涡和波环由本项目原创；参考用户指定的Emotive Engine环绕发射源码，使用固定版本three.quarks 0.17.1绘制共享拖尾和命中粒子。没有引入参考项目的模型、纹理或Emotive Engine运行库；源码入口与适配说明见[招式参考](docs/elemental-references.md)。

五行盾参考[Flow Shield](docs/shield-reference.md)的透明边缘、显隐和球面命中结构，在纯Three.js中重新创作元素纹样及防御规则；无新增模型/纹理/运行库。近墙镜头进球时保留低透明内侧。

天气参考Tideline的天空、云与实例雨思路；月亮按用户最新要求采用Emotive Engine原4K月面贴图、Full Moon表面公式与面向校准，不重绘月海、环形山或染色。未引入整个引擎或模型，详见[天气与Moon参考](docs/weather-references.md)。日弧按本机时钟映射06:00–18:00，固定满月为美术表现，当前不模拟实际日期月相、季节日长或在线天气。

太阳参考hizzd/threejs-earth-sun的暖色发光感，原创乳金日盘、晨昏橙金边缘、两层光晕与柔和射线；按用户要求将直径放大5倍，云层遮挡、海面反射共用外观。按P调时间、云量与雨；17:18可看巨型日盘和日落倒影。

云层随时间缓慢飘动，手动固定时刻后仍会流动，海面倒影同步；暂停游戏时停止，恢复后继续。可按P选择阴天，再关闭面板观察。实机连续画面与验证见[云流动验收](artifacts/cloud-drift-20261008/README.md)。

## 验证与静态发布

```sh
npm test
npm run inspect:canvas -- --headed --manifest artifacts/evidence.json --url 'http://127.0.0.1:4194/?test=1' --seed 42
python3 /home/ryan/.codex/skills/threejs-game-director/scripts/check_evidence.py . --manifest artifacts/evidence.json
```

测试在本机图形会话中使用独立 Chromium 窗口、单 worker。无图形界面的 CI 可设置 `CI=1` 使用 headless；软件渲染结果可检查功能和像素，不能证明硬件 FPS。首次使用需要 `npx playwright install --no-shell chromium`；Ubuntu 26.04 的 Playwright 安装器兼容平台可设 `PLAYWRIGHT_HOST_PLATFORM_OVERRIDE=ubuntu24.04-x64`。

`dist/` 可放到 HTTP 静态服务的根目录或子目录，Vite 使用相对资源路径，不需要服务端路由。直接以 `file://` 打开不属于支持的运行方式。默认生产入口隐藏测试工具；显式 `?test=1` 为 QA 开启场景 hooks 与 diagnostics，不包含玩家作弊菜单。

当前开发预览按需求保留天气面板。发行时可用 `VITE_WEATHER_PANEL=0 npm run build` 关闭云图标和P入口；现实昼夜与天气仍工作。
